# frontend

Vue 3 + Vite + TypeScript + Tailwind v3。构建产物是纯静态的，丢给 Nginx 就行 ——
只有两个例外，都是**运行时向后端要的**（见 `backend/`）：
**留言页的留言**（SQLite）与**影像页的照片清单**。
所以线上要把 `/api` 反代到 backend，开发时 vite 已经代理好了。
后端没起**只影响这两块**：项目正文与前四个视图仍在前端，照常显示
（留言页会明说“读不到”，照片墙留空）。

## 这个站在做什么

李泽敖的个人主页 —— **不是简历站，不是作品集，不是面板，也不是博客。**

### 视觉主题

**手绘 × 自然 × 插画 × 私人生活感。**

一句话：一个年轻人的私人小世界，被画成了一组网页空间。
它是「一间屋子和它窗外的湖」，不是「一个用来展示成果的容器」。

## 手机（窄屏）

站是按桌面视口画的，但**手机要能用**。断点只有一个 **640px**（Tailwind 的 sm），
≤480px 再收一档（目前只有照片墙的列数用到这条）。

窄屏上只做三件事，**不做第二套版式**：

1. **景里的字落到画下面的纸上**。画是 2848:1602 的横幅，手机竖屏下只有约
   四分之一屏高，字压在画上会被裁（理由见 `SceneStage.vue` 末尾那段）。
2. **正文的边距与列数收一档**：`.shell` 内边距 2rem → 1.25rem，
   清单的序号槽 4rem → 2.5rem，「结果」的数字 11rem → 8.5rem（好排两列），
   照片墙三列 → 两列，表格字号与列间距各收一点。
3. **可点范围托到 44px**（WCAG 2.5.5）：导航链接、景里的热点、
   「写上去」、详情页的「做过的东西」。做法是 padding / 伪元素外扩 +
   等量负 margin —— **盒子长在字外面，版式一格不动**。

另外两条容易漏的：

- `html` 的 `scrollbar-gutter: stable` 在窄屏要撤掉：手机没有占位型滚动条，
  留那条位只会让整页内容横着偏出中心半条（15px 落在右边）。
- 输入框字号在窄屏要 ≥16px：iOS Safari 会对小于 16px 的输入框自动放大整页。
