# 0008. 场景页：湖边与屋里

- 状态：已接受
- 日期：2026-09-17

## 背景

站点后来得到了一套独立设计的「湖畔场景」原型（原 `frontend/1/`，现已删除）：
两页 100vh 不滚动的插画场景，用 Python 脚本从分层图算出百分比坐标拼出来的。

- `index.html`：湖边。远景树丛 / 垂柳 / 红顶小木屋 / 木栅栏 / 躺卧少年 / 雏菊花丛，
  各层有极轻微的摇曳或呼吸动效，小屋可点。
- `room.html`：屋内。书桌上有三叠书、一台电脑、一台相机、一只杯子、一张便签，
  其中三样可点。

两个问题必须先回答：

1. **这套水彩插画的视觉语言和既有的「新中式治愈系」不是同一套。**
   原型写死了 `#b8703f`、`#fdf8ee`、`Noto Serif SC`，没有暗色模式，
   没有纸感噪点，没有手绘边框。
2. **34 MB 的 PNG。** 原型目录里 `img/` 15 MB + `img2/` 19 MB，
   其中 `composite.png` 两份共 17 MB 是**合成参考图**（用来验证图层位置的，页面用不到），
   另有已删除的图层素材和 28 MB 的调试残留。

## 决定

**两个场景成为站点的两页，但把颜色收进 CSS 变量里。**

- 场景页保留自己的**构图**：16:9 舞台、100vh 不滚动、按参考画布百分比定位的图层。
  这是它们与内容页的区别，不动。
- 场景页的颜色走变量（`--scene-paper` / `--scene-wood` / `--scene-ink` 等，
  见 `main.css`），并**补上暗色模式**。原型的色值原样搬进变量，不另发明颜色。
- 图层坐标全部进 `src/data/scenes.ts`，两个场景共用 `SceneStage.vue`。
  三叠书「当一个组件」用数据里的 `group` 字段表达，不再用 `:has()` 选择器。
- 动效遵守 ADR-0005：只做物件自身的呼吸 / 摇曳，悬停只缩放。
  **不做跟随鼠标的视差，不加光晕和投影。**
- 素材转 WebP（长边压到 2400），`composite.png` 不进仓库，
  转换脚本是 `scripts/build-scenes.mjs`，原始目录删除。
  34 MB → 843 KB。
- 图层定位与可点区域的计算脚本收进 `scripts/`（`scene-locate-layers.py`、
  `scene-build-zones.py`）。**改素材之后要重跑这两个脚本，不要手调百分比。**

## 后果

**与既有 ADR 的关系**：ADR-0005 的动效包线继续有效，场景不豁免。
ADR-0001 的「新中式治愈系」定位不变 —— 场景页是它的一个房间，不是另一套品牌。

**两个原型的页面被丢掉**：`studio.html`（小屋里面的过场页，只是走廊）、
`about.html` / `books.html` / `photos.html`（三个内容页的示范稿）。
它们的内容由真正的 Vue 页面承担，见 ADR-0009。

**踩过的坑写进了 `SceneStage.vue` 的注释**，改那个组件之前先读：

- 可点区域不能用 `clip-path` 抠轮廓 —— 实测 `elementFromPoint` 完全无视它，
  电脑的透明处会把压在它下面的书抢走。所以物件本体不接鼠标，
  上面压几个互不重叠的透明小块。
- `.hot` 容器的子元素如果全部绝对定位，它的高度是 0，
  可点区域的百分比会全部解析成 0，点击区整体消失。
  必须有一层在流内撑高。

**未解决**：竖屏手机。舞台维持 16:9 会变成一条窄带
（390×844 的机器上只有 390×219），文字和热点都太小。
现在的处理是让文案落到舞台下方的空白区、并给热点隐式扩大命中范围，
但**没有为竖屏重新设计构图**。这是一件独立的、需要美术判断的事。
