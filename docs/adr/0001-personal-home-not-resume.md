# 0001. 放弃简历定位，重构为治愈系个人站

- 状态：已接受
- 日期：2026-09-16

## 背景

本站在 commit `6245680`（「面向招聘方的极简专业简历站 + 像素点缀」）中被定位为：

> 以求职为主、兼顾技术展示的个人简历站。主要读者是招聘方 / HR / 面试官，次要读者是同行开发者。

围绕这个定位，`frontend/README.md` 建立了一整套强制约束：白底大留白、圆角一律为零、2px 实线边框、无模糊硬阴影、全站只有一个强调色（复古蓝）、动效克制（无视差、无粒子、无打字机）、正文不做任何像素化。

这套约束把「专业」推到了组织原则的位置，也把网站的形态锁死了。

## 决定

**放弃简历站定位，重构为个人主页（personal home on the web）。**

- 定位：关于我、我写的东西、我拍的照片。「我的」是组织原则。
- 读者：任何点进来的人。招聘方也在其中，但不为招聘方做优化。
- 风格：整体重构为《罗小黑战记》视觉特征衍生的**新中式治愈系**，拆解见 `CONTEXT.md`。

重构在**原仓库原架构内进行**：保留 Vue 3 / Vite / TypeScript / Tailwind v3、Markdown 笔记管道、照片目录约定、vue-router、CSS 变量令牌 + Tailwind 映射 + `useTheme` 的架构。这些基础设施与定位无关。

## 后果

**被推翻的旧约束**（`frontend/README.md` 的约束表整体作废）：

| 旧约束 | 现状 |
|---|---|
| 极简专业打底（白底） | 改为米白 / 暖灰 / 淡茶，明确拒绝纯白 |
| 圆角为零 | 改为圆角或不规则手绘边框 |
| 2px 实线边框 | 改为手绘线条，禁止绝对笔直的几何边框 |
| 无模糊硬阴影 | 改为色块偏移 / 手绘排线，仍然不用真实投影 |
| 动效克制（无视差） | 改为克制的环境动效，包线见 ADR-0005 |
| 全站只有一个强调色 | 改为自然色系 + 极少量点亮色 |
| 正文不做像素化 | 像素语言整体退役，见 ADR-0002 |

**保留下来的**：明暗两套、行高偏大、留白优先、中文单语、正文不做装饰性处理。

**内容结构变化**：原本独立的 `/projects` 折进 `/about`，`/notes` 与 `/gallery` 成为两根支柱。

- `/about` 新增「做过的东西」一节，直接列出三个项目。
- `/projects/:slug` 详情页保留：项目详情是真正的长文内容，值得单独链接。
- `/projects`（列表页）重定向到 `/about`。旧地址可能被外部引用过，直接删会掉进 404 兜底页。
- 导航不再有「项目」一项。

## 备注

定位决定了设计。原先那套约束不是错的，是**为另一个目标服务的**：它们让一家公司能在三十秒内读懂候选人。目标换成「这是我自己的地方」之后，同一个约束集就从「专业」变成了「僵硬」。

`New.md` 是一次性的风格 brief（已删除），其内容已并入 `CONTEXT.md`。
