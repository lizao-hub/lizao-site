# 0002. 手绘线条取代像素语言

- 状态：已接受
- 日期：2026-09-16

## 背景

本站曾有一套完整的像素语言：

- `PixelIcon.vue`：8×8 手绘点阵图标，被 **13 个文件**引用，是实际的图标系统，不是点缀
- `PixelRunnerGame.vue`（284 行）+ `usePixelRunner.ts`（400 行）：首页的像素跑步小游戏
- `main.css` 里约 150 行像素零件：`.pixel-btn`、`.pixel-tag`、`.pixel-photo`、`.pixel-rule`、`.pixel-num`、`.pixel-badge`
- 令牌 `--pixel-shadow: 4px 4px 0 var(--line)`：硬偏移阴影，是旧视觉里唯一的立体手法
- 字体 `Press Start 2P`

新风格的核心是**手绘线条**（非矢量完美的抖动、粗细变化、笔触质感）。像素网格与手绘线条是两种不兼容的美学：前者把精度推到极端，后者刻意放弃精度。

## 决定

**像素语言整体退役。** 不保留、不隔离、不「只放在游戏里」。

1. 删除 `PixelRunnerGame.vue` 与 `usePixelRunner.ts`，移除 `HomeView.vue` 里的引用。
2. 用新的内联 SVG 手绘图标集替换 `PixelIcon.vue`，覆盖全部 13 个引用点。保留原接口（`name` 属性、`currentColor`），让调用点改动最小。
3. 删除 `main.css` 里的像素零件与 `--pixel-shadow` 系列令牌，由手绘边框 / 色块偏移取代。
4. 移除 `Press Start 2P` 字体依赖。

删掉的代码不搬运到 `src/experiments/` 之类的目录：未被引用的代码会腐坏，也会给「以后再加一个页面放它」留下借口。git 历史就是归档。

## 后果

- 首页失去一个小游戏。这是有意的：它是一个为旧定位服务的「作品展示」，在个人主页里没有位置。
- 图标系统必须重建。这是本次重构中工作量最集中的一块，也是**最容易做得像模板**的一块。不引入风格不匹配的第三方图标库：手绘图标必须与手绘边框共享同一套线质。
- 旧的造型手法（硬偏移阴影）消失，立体感改由手绘排线与色块错位承担。这会让界面整体更平、更软。
