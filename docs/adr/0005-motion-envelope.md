# 0005. 动效克制包线

- 状态：已接受
- 日期：2026-09-16

## 背景

新风格要求**灵动**：加载动画不用转圈（改眨眼、摇尾、落地、灵力光点汇聚），悬停有弹性形变 / 漂浮感 / 颜色晕染，滚动可以柔和视差，背景的云朵落叶缓慢飘动，还有粉丝向的彩蛋。

旧约束则是「动效克制，只有 CSS hover、路由交叉淡入、区块滚动淡入，没有视差、没有粒子、没有打字机」。

两个方向都合理，但**没有包线的「灵动」会变成一个卡顿的网站**：滚动联动的视差在滚动路径上每帧计算，是移动端掉帧和耗电的首要来源。

## 决定

采用**克制的环境动效**，具体包线：

保留：
- 悬停反馈：轻微弹性形变、漂浮、颜色晕染。这是「Q 弹」的主要来源，成本低、收益高。
- 区块滚动淡入（`IntersectionObserver`，触发一次，沿用现有 `SectionFade.vue` 的思路）。
- 首屏的环境动效：云朵 / 落叶的缓慢飘动，仅限 hero 区域。

不做：
- ~~滚动联动的视差（scroll-linked parallax）。滚动路径上不留任何逐帧计算。~~
  **已于 ADR-0007 放开，限首页封面。**
- 全站常驻的背景粒子层。
- 打字机效果。

硬性要求：
- **`prefers-reduced-motion: reduce` 必须关掉全部环境动效**，只保留最基础的 hover 变色。这不是可选项。
- 所有环境动效走 `transform` / `opacity`，不触碰会触发布局的属性。

## 后果

「森林漫步」的沉浸感主要在首屏和悬停反馈里实现，页面滚动时是安静的。这是刻意的取舍：个人站不该在别人的中端手机上掉帧。

**修订（ADR-0007）**：滚动联动视差已在首页封面上解禁。该条的其余部分仍然有效：
`prefers-reduced-motion` 必须关掉全部环境动效；动效只走 `transform` / `opacity`；
滚动路径上不做逐帧的布局计算。后续要在别的页面也用视差，直接引用 ADR-0007，
不用再改本文件。

将来若要放开某一条（比如某个页面加滚动视差），需要新开一条 ADR 说明为什么那一处值得，而不是把整条包线放宽。
