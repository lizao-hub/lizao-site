# 0004. 暖调暗色模式：明暗同源

- 状态：已接受
- 日期：2026-09-16

## 背景

新风格的光明模式是**宣纸**：米白、暖灰、淡茶色底色，墨色文字，低饱和的自然色。文件明确拒绝纯白。

原实现（`main.css` + `useTheme.ts`）保留「明暗两套」——手动的主题切换，localStorage 记忆，首屏之前生效。这套机制继续用。

但原来的暗色是中性冷灰（`--paper: #0f1115`、`--surface: #161a20`、`--line: #2a2f37`）。那个配色服务的是旧的「极简专业」定位，与新的暖色纸感不是同一个世界。

## 决定

**暗色模式是同一个世界的夜晚，不是把变量反相。**

- 底色走**暖调墨夜**：深而不纯黑的暖灰 / 墨绿褐，而不是中性冷灰。
- 文字是暖调的纸白，不是纯白。
- 自然色（森林绿、天空蓝、木质棕）整体降饱和后保留色相，让绿色还是绿色、蓝色还是蓝色，只是夜里更沉。
- 点亮色略微加暖，模拟灯火。

一条硬性注意事项：**纹理必须按模式重新制作。** 光明模式的宣纸颗粒叠在深色底上会读成「屏幕脏了」，而不是「纸」。两种模式各自需要一套噪点 opacity / blend 参数。

## 修订（2026-09-17）

**手动主题切换摸掉了。** `ThemeToggle.vue` 与 `src/composables/useTheme.ts` 删除。

明暗现在**只跟随系统偏好**：`index.html` 里的预置脚本读 `prefers-color-scheme`，
所以暗色模式仍然存在、仍然在首屏之前生效，只是不能再手动选。

- `localStorage` 里的 `lizao-theme` 仍然**照读不照写** ——
  以前手动选过深色的人不会被突然改回浅色，但再也改不回去了。
- 暗色令牌（`.dark`、`--paper` 等等）全部保留，它们仍然生效。

**后果**：这个 ADR 里「手动的明暗切换」这条不再成立。
如果再想要手动切换，需要把 `useTheme.ts` 和那个按钮找回来（在 git 历史里）。

## 后果

- 换主题时不只是变量反相，两套令牌都要**逐条设计**，工作量比原来大。
- 暗色下图片和照片的表现要单独检查：暖调暗底会染到照片的观感，Lightbox 的遮罩色（原 `--veil: #08090b`）也要跟着重挑。
- 好处是暗色模式不再是「同一个模板的夜间配色」，而真有夜晚的感觉——这恰好是「治愈系」在暗色下的落点。
